## インストール

### A — ブラウザで使う（R不要）

以下のリンクを開くだけで使えます。インストール不要：

**https://long-rh.github.io/AutoXP3-shinylive/**

WebAssembly（Shinylive）によりブラウザ内で R が動作します。

### B — ローカルで動かす (exeファイル)
以下のリンクをからexe.zipをインストール：

**https://github.com/long-rh/AutoXP3-shinylive/releases/tag/exe**

zipを解凍し、AutoXP3.exeをダブルクリックすると、インターネットなしでアプリを使用できます。

### C — ローカルで動かす (Rコード)

#### ステップ 1 — R をインストールする（R ≥ 4.1 が既にある場合はスキップ）

公式 CRAN サイトから OS に合ったインストーラーをダウンロードして実行します：

| OS | インストーラー |
|---|---|
| Windows | https://cran.r-project.org/bin/windows/base/ |
| macOS | https://cran.r-project.org/bin/macosx/ |
| Linux | https://cran.r-project.org/bin/linux/ |

通常のシステムインストールで問題ありません。パッケージの隔離は次のステップの `renv` が行うため、同一マシン上の他の R プロジェクトと競合しません。

#### ステップ 2 — クローンとセットアップ

```bash
git clone https://github.com/long-rh/AutoXP3-shinylive
cd AutoXP3-shinylive/myapp
Rscript setup.R
```
以下のリンクをクリックすると、ブラウザでアプリを使用できます。
```bash
Listening on http://127.0.0.x.x
```
`setup.R` は [**renv**](https://rstudio.github.io/renv/) を使って `shiny`・`readxl`・`writexl` をプロジェクト専用ライブラリ（`myapp/renv/library/`）にインストールします。システムの他の R パッケージとは完全に分離されます。マシンごとに1回だけ実行してください。**回線速度によっては、ライブラリのインストールに時間がかかる場合があります。**

#### ステップ 3 — アプリを起動する

```bash
Rscript -e "shiny::runApp('.')"
```

> **注**: `renv/library/` は `.gitignore` で除外されています。初回実行後に `renv.lock` を commit することで、パッケージのバージョンがリポジトリに記録されます。

## 1. AutoXP3 とは

![起動直後の画面](img/1.png)
*▲ 起動直後の画面。左パネルでファイル操作、右の 4 タブで分析を進める。*

AutoXP3 は、**セミパラメトリック・ベイズ回帰**と **UCB（Upper Confidence Bound）獲得関数**を組み合わせた実験最適化ツールです。入力変数（X）と出力変数（Y）の実験データを Excel で与えると、ガウス過程（GP）モデルを自動構築し、Purpose で指定した目標に向けて次の実験条件の候補を提案します。

連続変数とカテゴリ変数が混在するデータに対応しており、複数の出力変数を同時に扱う多目的最適化も可能です。

### 画面構成

| パネル / タブ | 役割 |
|---|---|
| 左パネル | ファイルアップロード（Browse...）、Fit all Y、Save Result、変数情報の表示 |
| **1. Data** | アップロードしたデータ・変数定義・制約の確認 |
| **2. Model** | ハイパーパラメータ設定とモデル精度の確認 |
| **3. Analyze** | GP モデルによる予測カーブの可視化 |
| **4. Optimize** | 次の実験候補点の生成 |

## 2. Excel テンプレートの準備

AutoXP3 にアップロードする Excel ファイルは **2 つのタブ**（`Data`・`Definition`）で構成されます。画面左下の「**Download Template**」リンクからテンプレートを入手してください。

### Data タブ

![Data タブ](img/0a.png)
*▲ Data タブ。1 列目に実験識別子（`id`）、以降に入力変数・出力変数の実測値を行ごとに記録する。*

1 列目は実験の識別子（`id`）、続いて入力変数（X1, X2, X3）と出力変数（Y1）の実測値を行ごとに記録します。カテゴリ変数（X3）は文字列（A / B など）で入力します。1 行 1 実験点です。

### Definition タブ

![Definition タブ](img/0b.png)
*▲ Definition タブ。各変数の探索範囲・種類・目的を定義する。*

各変数の探索範囲・種類・目的を定義します。列の意味は以下の通りです。

| 列名 | 必須 | 説明 |
|---|:---:|---|
| Parameter | ○ | 変数名（Data タブのヘッダーと完全一致させる） |
| Min | ○ | 探索下限。連続変数は数値、カテゴリ変数は水準値（例: A） |
| Standard | 推奨 | Analyze タブで他の X を固定するときのデフォルト値 |
| Max | ○ | 探索上限。連続変数は数値、カテゴリ変数は別の水準値（例: B） |
| Type | ○ | `continuous`（連続）または `categorical`（カテゴリ） |
| Interval | 推奨 | 連続変数の候補グリッド間隔（次の実験提案の刻み幅）。省略すると範囲を 20 等分 |
| Purpose | ○（Y のみ） | 最適化の目標方向（下記参照） |

#### Purpose の記法

| 記法例 | 意味 | UCB スコアの計算式 |
|---|---|---|
| `>` または `>0` | 最大化（閾値 0 から上を目指す） | `(μ - 0) + κσ` |
| `>5` | 5 を超えることを優先して最大化 | `(μ - 5) + κσ` |
| `<` または `<0` | 最小化 | `(0 - μ) + κσ` |
| `<5` | 5 未満を優先して最小化 | `(5 - μ) + κσ` |
| `=5` | 目標値 5 にできるだけ近づける | `-\|μ - 5\| + κσ` |

> Y の列には **Purpose を必ず設定**してください。`>` なら大きいほど良い、`<` なら小さいほど良いという最適化の方向性をモデルに伝えます。

### 2.3 Constraints タブ（任意）

入力変数間の制約式を 1 行 1 式で記述します。`<` または `>` を含む文字列を記入すると、候補点の生成時にその条件を満たさない点が自動的に除外されます。

> **例:** `X1 + X2 < 4`（X1 と X2 の合計が 4 未満の候補のみ提案される）

## 4. モデルのフィット（2. Model タブ）

![2. Model タブ](img/3.png)
*▲ 2. Model タブ。左にハイパーパラメータ設定、右に予測値 vs 実測値の散布図（R² 表示付き）。*

### 4.1 採用モデル：セミパラメトリック・ベイズ回帰

AutoXP3 は線形成分と GP 非線形成分を組み合わせた次のモデルを使います。

```
y = X β + u + ε

β ~ N(μ₀, Σ₀)     ← 線形係数の事前分布
u ~ GP(0, K)       ← ガウス過程（非線形成分）
ε ~ N(0, σ² I)     ← 観測ノイズ
```

- **X**：切片を含む設計行列（n × p）
- **β**：線形係数ベクトル（p 次元）
- **u**：カーネル関数 K で規定される非線形偏差
- **ε**：観測ノイズ

線形成分が大域的な傾向を捉え、GP がそこからの局所的なズレを補正します。

### 4.2 カーネル関数

**連続変数：RBF カーネル**

```
k_RBF(xᵢ, xⱼ) = θ₁ · exp( -‖xᵢ - xⱼ‖² / (2ℓ²) )

θ₁ (RBF scale)  : 振れ幅スケール（固定値 1.0）
ℓ  (Lengthscale): 相関が減衰する距離スケール（デフォルト 0.4）
                  小さいほど局所的、大きいほど滑らかな予測
```

**カテゴリ変数：デルタカーネル**

```
k_cat(cᵢ, cⱼ) = σ_cat² · 1(cᵢ = cⱼ)

カテゴリ変数が複数ある場合は各デルタカーネルを加算：
K_cat = Σ_l  k_cat^(l)
```

**全体の共分散行列**

```
V = K_RBF + K_cat + σ² I     （n × n）
```

### 4.3 ベイズ更新：β の事後分布

データ y を観測したとき、β の事後分布は解析的に得られます。

```
事後精度行列 :  Q    = Σ₀⁻¹ + Xᵀ V⁻¹ X
事後共分散   :  Σ_β  = Q⁻¹
事後平均     :  μ_β  = Σ_β ( Σ₀⁻¹ μ₀ + Xᵀ V⁻¹ y )
```

事前共分散 Σ₀ の対角値が大きいほど GP に主導権を渡し、小さいほど線形回帰に近づきます。

### 4.4 予測分布

新しい点 x\* における予測平均と予測分散は次式で計算されます。

```
予測平均：
E[y*|y] = x*ᵀ μ_β + k*ᵀ V⁻¹ (y - X μ_β)

予測分散（3 成分の和）：
Var[y*|y] = σ²                   ← 観測ノイズ
          + k** - k*ᵀ V⁻¹ k*    ← GP 不確実性（未探索領域で大）
          + δᵀ Σ_β δ            ← 線形係数の不確実性

k*  = K(訓練点群, x*)    δ = x* - Xᵀ V⁻¹ k*
```

データが少ない領域では「GP 不確実性」が大きくなり、線形成分が不確かな領域では「線形係数の不確実性」が大きくなります。

### 4.5 標準化処理

モデルはフィット前に変数を内部で標準化してからカーネルを計算します。

```
連続入力変数 z :  z_s = (z - z̄) / s_z
出力変数 y    :  y_s = (y - ȳ) / s_y
```

予測値は元スケールに逆変換して表示されます。Definition シートの Min / Max / Standard は**元スケール**で記入してください。

### 4.6 ハイパーパラメータの設定

| パラメータ | デフォルト | 意味と調整目安 |
|---|:---:|---|
| Lengthscale（ℓ） | 0.4 | RBF カーネルの距離スケール。標準化後の空間で機能するため 0.1〜2.0 が目安。小さいほど局所的（過剰適合注意）、大きいほど滑らか。 |
| Noise（σ²） | 0.05 | 観測ノイズの分散。再現誤差が大きい場合は増やす。0 に近づけすぎると過剰適合の恐れ。 |

パラメータを変更したら **「Refit current Y」** で現在の Y のみ再フィット、または **「Fit all Y」** で全 Y を一括再フィットします。

### 4.7 Fitting result information の見かた

![Fitting result information](img/4.png)
*▲ Fitting result information — 事後パラメータ・ハイパーパラメータ・残差統計量が表示される。*

| 項目 | 説明 |
|---|---|
| `mu_beta[1]` (intercept) | 切片の事後平均（元スケール換算） |
| `mu_beta[2...]` (X 変数名) | 各連続変数の線形係数の事後平均（元スケール換算） |
| `theta1` (RBF scale) | RBF カーネルのスケール θ₁（固定値 1.0） |
| `theta2` (lengthscale) | RBF カーネルの距離スケール ℓ（ユーザー設定値） |
| `sigma2` (noise var) | 観測ノイズ分散 σ²（ユーザー設定値） |
| `sigma_cat` (cat. var.) | カテゴリカーネルの分散スケール σ_cat² |
| `eps var.` | 残差（ŷ − y）のサンプル分散。小さいほど良好なフィット |
| RMSE | 訓練データに対する二乗平均平方根誤差 |
| R² | 決定係数。1.0 に近いほど訓練データへのフィットが良好 |

> R² が低い（例: < 0.8）場合はハイパーパラメータの調整またはデータ量の確認を行ってください。訓練 R² ≈ 1 でも予測精度が低い過剰適合にも注意が必要です。

## 5. 予測の可視化（3. Analyze タブ）

![3. Analyze タブ](img/5.png)
*▲ 3. Analyze タブ。X 軸変数を選択すると GP の予測平均（実線）と予測区間（破線）が描画される。*

「3. Analyze」タブでは、1 つの入力変数を横軸にとり、GP モデルの予測を 1 次元プロットで確認できます。

### 5.1 グラフの見かた

| 要素 | 意味 |
|---|---|
| 実線 | 予測平均 `E[y* \| y]` |
| 破線 | 予測平均 ± 予測標準偏差 `sqrt(Var[y* \| y])`。データが少ない領域ほど幅が広がる。 |
| 黒点 | 実測データ点 |

### 5.2 操作方法

| 項目 | 説明 |
|---|---|
| X (horizontal) | グラフの横軸にする入力変数を選択 |
| X (vertical) | グラフの縦軸にする変数を選択（通常は出力 Y） |
| その他の X 変数 | Definition シートの Standard 値で固定（未設定の場合は Min 値） |

### 5.3 感度分析への活用

各入力変数を順番に X 軸に設定して可視化することで、どの変数が Y に最も強く影響するかを直感的に把握できます（感度分析）。信頼区間が広い領域は Optimize タブの Explore 候補として優先されやすい場所でもあります。

## 6. 次の実験点の提案（4. Optimize タブ）

![4. Optimize タブ（Suggest 前）](img/6.png)
*▲ 4. Optimize タブの初期状態。「Suggest next experiments」ボタンを押すまで候補は表示されない。*

![4. Optimize タブ（候補リスト）](img/7.png)
*▲ 「Suggest next experiments」実行後。Optimize / Explore の各モードで順位付きの候補リストが表示される。*

### 6.1 獲得関数：UCB（Upper Confidence Bound）

各候補点 x に対して、GP の予測平均 μ(x) と予測標準偏差 σ(x) から UCB スコアを計算します。スコアが高い候補ほど優先度が高いと判断されます。

```
UCB(x) = μ(x) + κ · σ(x)

μ(x) : GP の予測平均（大きいほど現時点で好ましい）
σ(x) : GP の予測標準偏差（大きいほど未探索・情報価値が高い）
κ    : 探索と活用のバランスパラメータ
```

Purpose の設定に応じてスコアの計算式が変わります。

```
Purpose >θ または >=θ : UCB = (μ - θ) + κσ
Purpose <θ または <=θ : UCB = (θ - μ) + κσ
Purpose =t（目標値）  : UCB = -|μ - t| + κσ
```

### 6.2 Optimize モードと Explore モード

AutoXP3 は κ の値を変えた 2 つのモードで候補を生成します。

| モード | κ | 意味 | 使いどころ |
|---|:---:|---|---|
| **Optimize**（活用） | 0 | `UCB = μ(x)` のみ。現在のモデルが最良と予測する条件付近を選ぶ。 | モデルが成熟したとき |
| **Explore**（探索） | 2 | σ(x) を強く重視。不確実性が高い未探索領域を積極的に試す。 | 初期フェーズ・モデルの改善が必要なとき |

### 6.3 多目的最適化：総合望ましさ（Desirability）

出力変数が複数ある場合、各 Y に対する UCB スコアを個別の望ましさに変換し、幾何平均による総合望ましさ D を計算します。

```
D(x) = ( d₁(x) · d₂(x) · … · dₘ(x) )^(1/m)
     = 全 Y 変数の個別望ましさの幾何平均

いずれか 1 つの d_i = 0 になると D = 0
→ 全ての目標に対してバランスよく最適化が進む
```

### 6.4 TargetY の意味

| TargetY の値 | 意味 |
|---|---|
| 変数名（例: `Y1`） | その Y 変数の個別 UCB スコアで順位付けした候補 |
| `All` | 全 Y 変数の総合望ましさ D で順位付けした候補（多目的最適化） |

### 6.5 候補テーブルの列の意味

| 列名 | 説明 |
|---|---|
| Candidate | 候補点の識別子（cand1, cand2, ...） |
| Mode | Optimize（κ=0）または Explore（κ=2） |
| TargetY | スコアリングに使った Y 変数名（単一 Y または `All`） |
| Rank in scope | 同じ Mode と TargetY の組み合わせ内での順位 |
| Desirability | 総合望ましさ D（0〜1。大きいほど優先度が高い） |
| X1, X2, X3, … | 提案される入力変数の値 |
| Pred.Y1, Pred.Y2, … | GP モデルによる各 Y の予測平均（元スケール） |
| SD.Y1, SD.Y2, … | GP モデルによる各 Y の予測標準偏差（元スケール） |

### 6.6 制約条件の適用

Constraints シートに制約式が記載されている場合、候補グリッド上で制約を満たさない点は最初から除外されます。候補テーブルに表示される点はすべて制約を満たしています。制約によって全候補が除外された場合はエラーメッセージが表示されます。

### 6.7 実験サイクルの進め方

1. 候補テーブルの上位から実験条件を選んで実験を実施する
2. 得られた Y 実測値を Data シートに追記して保存する
3. 再度アップロード → **「Fit all Y」** → **「Suggest next experiments」** を繰り返す
4. Desirability が目標値に近づいたら収束と判断できる

> **Tips:** 序盤は Explore 候補を多めに選んでモデルを成熟させ、R² が安定してきたら Optimize 候補に絞るのが効果的です。

## 7. 結果の保存

![Save Result ダイアログ](img/8.png)
*▲ 「Save Result」ボタンを押すと保存ダイアログが開く。デフォルトのファイル名には実行日時が付加される。*

## 8. アプリなしで結果を再現する

`REPRODUCTION_PROMPT.md` は、AI アシスタント（または開発者）が Shiny アプリを起動せずに、Excel ファイルだけから AutoXP3 の解析パイプライン全体を再現し、**「Save Result」と同形式の `.xlsx`** を出力するための機械可読仕様書です。

### 8.1 内容の概要

`myapp/R/` 以下の R 関数を参照しながら、計算の全ステップを正確に定義しています。

| セクション | 内容 |
|---|---|
| §0 前提 | 既定ハイパーパラメータ・ファイル構成・`set.seed(1)` ルール |
| §1 Excel パース | `parse_purpose()`・1D 候補リスト規則・カテゴリ水準の取得 |
| §2 標準化 | `standardize_fit()`・`prior_to_standardized_scale()`・`beta_to_original_scale()` |
| §3 ベイズフィット | `fit_semiparam_bayes()` の入出力・カーネル構成 |
| §4 候補生成 | LHS + コーナー格子（≤ 100 + 2048 点）・派生変数・制約フィルタリング |
| §5 予測 | `predict_semiparam_bayes()`（`var_total = σ² + v_gp + v_beta` 使用） |
| §6 訓練セット指標 | 原スケール残差から R²・RMSE・eps var. を再計算 |
| §7 UCB と満足度 | `ucb_score()` の分岐ロジック・個別 Y 満足度と幾何平均 |
| §8 スコープ結合 | `make_scope_df()`・重複除去・並び替え・`cand1..N` 採番 |
| §9 Excel 出力 | シート順・`Fit info` 行フォーマット（`sprintf` 仕様）・`Optimize` シート列 |
| §10 数値精度 | `round(..., 4)`・`jitter = 1e-8`・タイムスタンプ形式 |
| §12 参照出力例 | Sample8 の `Fit info` 期待値（数値検証用） |
| §13 注意点 | よくある間違い（事前分布スケール、LHS シード、`var_total` など） |

### 8.2 使いどころ

- 複数の Excel ファイルをコマンドラインで**バッチ処理**したい
- 最適化ロジックを自分の R または Python ワークフローに**組み込みたい**
- **GUI を使わず**に AI に Save Result Excel を生成させたい
- 独自実装が AutoXP3 の数値出力と一致するか**検証**したい

### 8.3 AI との使い方

1. R コードを実行できる AI アシスタント（例：Claude）との会話を開く
2. `REPRODUCTION_PROMPT.md` と入力 Excel ファイルを添付する
3. 次のようなプロンプトを送る：

   > 「REPRODUCTION_PROMPT.md に記載された R 関数の仕様に従って、添付の Excel ファイルを処理し、Save Result 形式の出力を生成してください。ハイパーパラメータは §0 の既定値を使用してください。」

4. AI が仕様書のステップに従って処理し、アプリと同じ `Data`・`Definition`・`Fit info`・`Optimize` シートを含む `.xlsx` を生成する

### 8.4 数値検証

`AutoXP3_samples_split/` フォルダの `Sample8.xlsx` を参照ファイルとして使用できます。プロンプトの §12 に `Fit info` シートの期待値が記載されています（例：切片 = `+21.559403`、R² = `0.9998`）。これらが一致すれば実装は正しいと判断できます。
